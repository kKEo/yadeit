# Part II: Install and deploy

How to put Yadeit on a server and keep it reachable over HTTPS, and how to run
it on your own machine for development.

- [Deploy with Docker Compose](docker.md): the supported production setup, from an empty server to the first operator.
- [HTTPS and proxies](https.md): your own proxy, or the container's automatic certificate.
- [Install without Docker](without-docker.md): the same parts by hand, and MariaDB.
- [Deploy on shared hosting (Zenbox)](shared-hosting.md): ordinary PHP hosting with SSH and cron, step by step, and what you give up.
- [Local development](local-development.md): backend and frontend on your machine, or the whole stack with `make app-up`.
