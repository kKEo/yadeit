# Built-in AI help

Yadeit can use an AI model (Claude, from Anthropic) to save you typing and
reading: drafting an item from one sentence, splitting big work, summarising a
long discussion or page, and suggesting what to do with feedback. This page
explains each feature and how to switch it on.

Everything AI produces is a **suggestion**, marked *Suggested by AI. Check it
before you use it.* Nothing is saved until a person accepts it.

## Switch it on

AI help is off until an admin or owner switches it on, because using it sends
text from your workspace to the AI provider.

1. Open **Settings** in the sidebar and find **AI help**.
2. Read the note on what is sent, then switch on **AI help for this
   workspace** and **Save**.

The same section shows how many tokens (the unit AI use is counted in) the
workspace used this month, and its **Monthly token limit**. When the limit is
reached, AI help pauses until next month.

The workspace uses the installation's AI key by default. An admin can enter
the workspace's **Own Anthropic API key** instead; a saved key is never shown
again, and **Remove own key** goes back to the installation's key. If neither
exists, the section says no provider key is available.

Members, admins and owners can use AI help. Guests and agents cannot.

## Draft an item from one sentence

In the new item form, write what you need in one sentence and choose **Draft
with AI**. You get a title, a **Description** and **Acceptance criteria**.
Edit what you want, then create the item, or **Discard the draft**.

## Split an item into sub-items

On a big item, choose **Suggest sub-items**. Tick the proposals you want and
choose **Create selected**. If the item is small enough already, it says so.

## Summarise a discussion or a page

On an item with a long thread, or on a doc page, choose **Summarise**. The
summary lists what was **Decided**, what is **Still open** and the **Key
points**. It is not saved; it is there to read.

## Suggest what to do with feedback

On a feedback entry, choose **Suggest**. It may say the entry *looks like a
duplicate*, that an existing item *already covers this*, or propose a *New
item* with a kind and priority. One click applies the suggestion; you can also
ignore it and decide yourself.

## Good to know

- Suggestions can be wrong. Read them as a colleague's draft.
- The AI sees only the text needed for the one suggestion you asked for, at
  the moment you ask. See [Trust and privacy](trust-and-privacy.md).
- Built-in AI help is separate from [agents](agents.md). Agents are members
  that do work over time; AI help is a button that drafts something for you
  now.
