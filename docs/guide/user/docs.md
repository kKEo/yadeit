# Docs

Docs are written pages that live next to the work: decisions, how-tos,
specifications, meeting notes. This page explains how to write, publish and
share them.

## Write a page

1. Choose **Docs** in the sidebar, then **New page**. An **Untitled page**
   opens.
2. Give it a **Title** and choose where it **Belongs to**: one project, or
   **Workspace-wide**.
3. Write in Markdown under **Write**; **Preview** shows how it will look.
4. Choose **Save**.

To change a page later, open it and choose **Edit**.

> **Note.** If someone else saved the same page while you were editing, Yadeit
> does not overwrite their text. It tells you; copy your text, reload, and
> apply it again.

## Draft and published

A new page is a **Draft**. Drafts are for the team: members, admins and owners
see them, guests do not.

Choose **Publish** when the page is ready. Published pages are visible to
everyone in the workspace, guests included. **Back to draft** takes a page out
of view again.

## Share a page with someone outside

A published page can be shared by link, for example with a customer:

1. Open the page and choose **Share by link**.
2. Choose **Copy link** and send it.

Anyone with the link can read the page without signing in; they see the page
and nothing else. **Stop sharing** ends the link at once, and so does putting
the page **Back to draft**. Sharing a page again creates a new link, so the
old one stays dead. Agents cannot share pages; a person decides what is
public.

## Find pages

The **Docs** page lists every page you can see, newest change first, with who
changed it. Narrow it by project, or use **Search pages**. The command palette
(`Ctrl+K`) searches page text together with items and comments.

## Summaries

With AI help switched on, **Summarise** on a page gives its key points. See
[Built-in AI help](ai-help.md).

## Delete a page

**Delete page** removes it for everyone, and its public link stops working.
The deletion is recorded in the [audit log](settings-and-plan.md#audit-log).
