# Keyboard and command palette

Almost everything in Yadeit can be done without the mouse. This page lists the
shortcuts and explains the command palette. Press `?` at any time in the app to
see the same list.

Shortcuts are switched off while you type in a field, so typing a `c` in a
comment never creates an item. On a Mac, use `Cmd` where this page says
`Ctrl`.

## The command palette

Press `Ctrl+K` and start typing. The palette does three things at once:

- **Runs commands** such as *Switch to board layout*, *Show design work*, a
  saved view, or *Switch to workspace …*.
- **Acts on the item you are looking at**: change its state, priority,
  assignee or labels, *Assign to me*, *Copy key*, *Copy link*.
- **Searches** items, comments and pages for every word you type.

Use the arrow keys to choose and `Enter` to run. `Escape` closes it.

## General

| Keys | Does |
|---|---|
| `Ctrl+K` | Open the command palette |
| `?` | Show keyboard shortcuts |
| `C` | Create an item |
| `Escape` | Close the item panel |

## Go to

Press `G`, let go, then the second key.

| Keys | Goes to |
|---|---|
| `G` then `I` | Items |
| `G` then `P` | Projects |
| `G` then `M` | Members |
| `G` then `N` | Inbox |

## Item list

| Keys | Does |
|---|---|
| `J` or `↓` | Next row |
| `K` or `↑` | Previous row |
| `Enter` or `Space` | Open the focused row |
| `/` | Focus the search box |

## The focused or open item

| Keys | Does |
|---|---|
| `S` | Change state |
| `P` | Change priority |
| `A` | Change assignee |
| `L` | Change labels |
| `I` | Assign to me |

The property picker that opens is the same one the mouse uses: type to
narrow it, arrows to choose, `Enter` to apply.

## Inbox

| Keys | Does |
|---|---|
| `J` / `K` | Next and previous notification |
| `Enter` | Open it |
| `U` | Mark read or unread |
| `H` | Snooze |
| `Backspace` | Delete the notification |

## Feedback

| Keys | Does |
|---|---|
| `J` / `K` | Next and previous feedback |
| `1` | Accept as a new item |
| `2` | Decline |
| `3` | Mark as duplicate |
| `H` | Snooze until tomorrow |

## A keyboard-only walk-through

1. `G` `I` to go to items.
2. `C`, type a title, `Enter`: a new item.
3. `J` / `K` to reach it, `S` to set **In progress**, `I` to take it.
4. `Ctrl+K`, type *board*, `Enter`: the board layout.
5. `?` if you forget any of this.
